# 🧠 [지식화] 빈 PDF 소스 기반 AI 영상 자동화 제작 및 오디오 교체 가이드

이 문서는 '초보자도 바로 갓생 사는 집중력 치트키 3가지'라는 주제로, 빈 PDF 파일이라는 제약 조건을 극복하고 AI 툴(이미지 생성, TTS)과 Python(MoviePy)을 활용하여 2분 분량의 고품질 영상을 제작한 전 과정을 정리한 지식 문서입니다.

---

## 1. 프로젝트 개요
- **목표**: '집중력 치트키 3가지'를 주제로 한 2분 분량의 나레이션 및 자막 포함 영상 제작.
- **주요 문제**: 제공된 소스 PDF 파일이 0바이트(빈 파일) 상태였음.
- **해결 방식**: 웹 검색으로 콘텐츠 확보 + AI 이미지 생성 + gTTS + MoviePy 합성 + 사후 오디오 교체.

---

## 2. 프로세스 단계별 트러블슈팅 및 해결 방안

### 2.1 소스 파일 부재 해결 (웹 검색 롤백)
- **문제**: 제공된 PDF 파일(`이거 생각보다 너무 쉬운데 초보자도 바로 '갓생' 사는 집중력 치트키 3가지.pdf`)의 크기가 0바이트여서 내용을 읽을 수 없었습니다.
- **해결 방안**: 파일 제목을 키워드로 웹 검색을 수행하여 대중적으로 알려진 '집중력 치트키 3가지'(환경 분리, 포모도로 기법, 생각 정리 노트)의 내용을 확보하고 이를 바탕으로 대본을 재구성했습니다.

### 2.2 비주얼 및 오디오 에셋 생성
- **이미지 생성**: 영상의 '프리미엄 감성'을 위해 AI 이미지 생성 툴을 활용하여 각 섹션에 맞는 4장의 고화질 일러스트/사진을 생성했습니다.
- **나레이션 생성 (gTTS)**: `gTTS` 라이브러리를 활용하여 한국어 음성을 생성했습니다. 기본 속도가 다소 느려 '늘어지는 느낌'을 주기 때문에, MoviePy 합성 단계에서 **1.25배속으로 가속**하여 세련된 템포를 확보했습니다.

### 2.3 자막 잘림 방지 (Pillow 직접 렌더링)
- **문제**: MoviePy의 `TextClip`은 한글 폰트 렌더링 시 하단이 잘리거나 가독성이 떨어지는 고질적인 문제가 있습니다.
- **해결 방안**: 이전 지식을 활용하여 `Pillow` 라이브러리로 반투명 배경 바와 글자가 합쳐진 고해상도 자막 이미지(`RGBA`)를 직접 생성한 후, 이를 `ImageClip`으로 불러와 합성했습니다. 이 방식은 자막 잘림을 100% 방지합니다.

### 2.4 사후 오디오 트랙 교체
- **문제**: 이미 생성된 완성본 영상(`focus_cheatkey_video.mp4`)에 사용자가 새로 제공한 오디오 파일(`Generated Audio May 13, 2026 - 3_38PM.wav`)을 덮어씌워야 했습니다.
- **해결 방안**: MoviePy의 `VideoFileClip`으로 기존 영상을 불러온 뒤, `with_audio()` 메서드를 사용하여 새로운 `AudioFileClip`을 적용하고 다시 렌더링했습니다. 오디오 길이가 비디오보다 짧았으나(105초 vs 120초), 비디오의 마지막 부분을 정지 화면처럼 유지하며 자연스럽게 처리했습니다.

## 3. 핵심 구현 코드 (Best Practice)

### 3.1 자막 이미지 생성 및 합성 (MoviePy 2.x 호환)
```python
from PIL import Image, ImageDraw, ImageFont
from moviepy import ImageClip

def create_subtitle_image(text, output_path, width=1024, height=120):
    # 반투명 어두운 회색 배경 (Alpha 200)
    img = Image.new('RGBA', (width, height), (40, 40, 40, 200))
    draw = ImageDraw.Draw(img)
    
    # 맑은 고딕 폰트 로드
    font = ImageFont.truetype("C:\\Windows\\Fonts\\malgun.ttf", 35)
    
    # 텍스트 크기 측정 및 중앙 정렬
    bbox = draw.textbbox((0, 0), text, font=font)
    text_width = bbox[2] - bbox[0]
    text_height = bbox[3] - bbox[1]
    
    x = (width - text_width) // 2
    y = (height - text_height) // 2 - bbox[1]
    
    draw.text((x, y), text, font=font, fill='yellow')
    img.save(output_path)

# MoviePy 2.x에서의 클립 생성 (with_ 메서드 사용)
sub_clip = ImageClip(sub_img_path).with_start(start_time).with_duration(duration).with_position(('center', 0.8), relative=True)
```

### 3.2 오디오 트랙 교체 코드
```python
from moviepy import VideoFileClip, AudioFileClip

# 비디오 및 새 오디오 로드
video = VideoFileClip("기존_비디오.mp4")
new_audio = AudioFileClip("새_오디오.wav")

# 오디오 교체 (MoviePy 2.x)
updated_video = video.with_audio(new_audio)

# 저장
updated_video.write_videofile("최종_비디오.mp4", fps=video.fps, audio_codec='aac')
```

## 4. 교훈 및 향후 과제
1. **에셋 부재 시의 유연성**: 원본 소스가 손상되었거나 비어있을 때, 인접 정보나 제목을 기반으로 **웹 검색을 통해 콘텐츠를 복원하는 롤백 전략**이 매우 효과적이었습니다.
2. **오디오 매칭**: 나레이션 오디오를 교체할 때는 기존 자막 및 화면 전환 타이밍과의 싱크를 맞추는 것이 중요합니다. 이번에는 단순 교체를 진행했으나, 완벽한 싱크를 위해서는 대본의 타임스탬프를 새 오디오에 맞게 재조정하는 과정이 필요할 수 있습니다.
