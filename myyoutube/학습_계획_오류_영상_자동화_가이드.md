이 문서는 '실패하는 학습 계획의 3가지 공통 오류' PDF를 바탕으로 AI 이미지 생성, TTS 음성 합성, 그리고 MoviePy를 활용한 영상 제작 전 과정을 정리한 지식 문서입니다. 특히 네트워크 제한 환경에서의 SSL 오류 해결과 오디오 길이에 따른 영상 연장 기법을 중점적으로 다룹니다.

  - **자막 렌더링**: `Pillow` (한글 폰트 깨짐 방지를 위한 이미지 자막 방식)

## 2. 주요 문제 해결 (Troubleshooting)

### 2.1 gTTS/Requests SSL 인증 오류 해결
- **문제**: 폐쇄망이나 특정 프록시 환경에서 `gTTS` 저장 시 SSL 인증 오류(`SSLCertVerificationError`)가 발생하여 0바이트 파일이 생성됨.
- **해결 방안**: `requests` 모듈을 몽키패치(Monkeypatch)하여 `verify=False` 옵션을 강제 적용.
```python
import requests
from gtts import gTTS

# Requests 몽키패치: 모든 요청에서 SSL 검증 제외
orig_get = requests.get
requests.get = lambda *args, **kwargs: orig_get(*args, **{**kwargs, 'verify': False})
orig_post = requests.post
requests.post = lambda *args, **kwargs: orig_post(*args, **{**kwargs, 'verify': False})

# 경고 메시지 무시
from requests.packages.urllib3.exceptions import InsecureRequestWarning
requests.packages.urllib3.disable_warnings(InsecureRequestWarning)
```

### 2.2 오디오 길이에 따른 영상 자동 연장 (Freeze Frame)
- **문제**: 새로 교체된 오디오가 기존 영상보다 길 경우, 영상이 먼저 끝나버려 검은 화면이 나오거나 싱크가 깨짐.
- **해결 방안**: 영상의 마지막 프레임을 이미지로 추출하여 부족한 시간만큼 연장한 뒤 오디오와 합성.
```python
from moviepy import VideoFileClip, ImageClip, concatenate_videoclips

video = VideoFileClip("video.mp4")
last_frame = video.get_frame(video.duration - 0.1) # 마지막 프레임 캡처
freeze_clip = ImageClip(last_frame).with_duration(extra_duration) # 연장 클립 생성

final_video = concatenate_videoclips([video, freeze_clip], method="compose")
```

## 5. 향후 개선 사항
1. **나레이션 속도 제어**: 현재 gTTS의 기본 속도는 다소 느리므로, MoviePy 단계에서 `1.1~1.25배속`으로 조절하면 더 세련된 느낌을 줄 수 있음.
2. **배경음악(BGM) 추가**: 나레이션 뒤에 잔잔한 배경음악을 깔아 풍성한 사운드 확보 필요.
