# [[윈도우 화면 캡처와 챗GPT를 활용한 컴퓨터 자가 수리]]

## 📌 Brief Summary
컴퓨터 화면이 갑자기 검어지거나 먹통이 되었을 때, 윈도우 캡처 단축키(`Win + Shift + S`)로 화면을 캡처한 후 챗GPT에 입력하여 쉽고 빠르게 해결 방법을 찾아내는 자가 수리 방법입니다.

## 📖 Core Content
컴퓨터 사용 중 갑작스러운 오작동이나 검은 화면 발생 시, 비싼 수리 비용을 들이지 않고 누구나 쉽게 해결할 수 있는 단계별 방법은 다음과 같습니다.

1. **화면 캡처하기**
   - 컴퓨터 화면에 오류가 발생했거나 먹통이 되었을 때, 윈도우 만능 캡처 단축키인 **`Win + Shift + S`**를 동시에 눌러 해당 화면을 캡처합니다.

2. **챗GPT에 이미지 전달하기**
   - 챗GPT 대화창을 열고, 캡처한 이미지를 그대로 붙여넣기(**`Ctrl + V`**) 합니다.

3. **해결 책 요청하기**
   - 이미지와 함께 **"고쳐줘"** 또는 문제 상황에 대한 간단한 질문을 입력합니다. 챗GPT가 이미지를 분석하여 마법처럼 신속하고 정확한 해결 방법을 제시해 줍니다.

이 방법은 컴퓨터 조작이 서툰 초보자나 50대 이상의 사용자도 대처 방법을 직관적으로 이해하고 3초 만에 문제를 해결할 수 있도록 돕습니다.
