# [[제2의 뇌: 노션과 옵시디언을 활용한 지식 베이스 구축]]

## 📌 Brief Summary
기존 폴더 정리 방식의 한계와 결정 피로를 극복하기 위해, 태그와 링크를 통해 지식을 유기적으로 연결하여 창의적인 인사이트를 도출하는 '제2의 뇌(Second Brain)' 구축 방법론입니다.

## 📖 Core Content

### 1. 기존 폴더 구조의 한계와 '제2의 뇌'의 필요성
* **결정 피로(Decision Fatigue):** 정보를 분류하고 저장할 폴더를 매번 고민하는 과정에서 뇌는 과부하 상태에 빠지게 됩니다.
* **지식의 고립:** 계층형 폴더 방식은 정보가 방대해질수록 지식을 서로 분리시켜 유기적인 융합을 방해합니다.
* **제2의 뇌(Second Brain):** 기억해야 한다는 압박감에서 벗어나 뇌의 과부하를 줄이고, 나만을 위한 디지털 지식 저장소를 구축하는 시스템입니다.
* **아이디어의 복리 효과:** 태그(#)와 링크([[]])를 통해 서로 다른 지식을 연결하면, 생각들이 충돌하며 새로운 인사이트가 지속적으로 창출되는 복리 효과를 누릴 수 있습니다.

### 2. PKM(개인 지식 관리) 4단계 핵심 프로세스
1. **1단계: 수집 (Capture)**
   * 머릿속을 비우기 위해 매일 마주하는 정보와 떠오르는 모든 생각을 하나의 '수집함(Inbox)'에 가볍게 던져 넣습니다.
2. **2단계: 원자적 메모 (Atomic Notes)**
   * 수집한 정보를 잘게 쪼갭니다. '하나의 메모에는 오직 하나의 아이디어만' 담아 블록처럼 조립하고 재사용하기 쉬운 형태로 만듭니다.
3. **3단계: 제텔카스텐 (Zettelkasten)**
   * 메모를 폴더에 가두지 않고, "이 생각이 다른 어떤 생각과 연결될 수 있을까?" 고민하며 링크를 통해 거대한 지식의 그물망을 짭니다.
4. **4단계: 에버그린 노트 (Evergreen Notes)**
   * 연결된 생각들을 정제하고 다듬어, 시간이 지나도 변하지 않고 계속해서 지속되는 나만의 영구적인 연구적 지식 자산으로 완성합니다.
